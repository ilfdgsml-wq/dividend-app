# 開拓ボードゲーム（仮）— Claude Code 用 指示文＆ルール仕様書

使い方：新しいフォルダでClaude Codeを起動し、このファイルを `docs/SPEC.md` として置いてから、下の「最初の指示文」を貼り付ける。
ルールは公式ルールブック（第5版英語版 Game Rules & Almanac, catan.com 配布PDF）に基づく。

---

## 1. 最初の指示文（Claude Codeに貼り付ける）

```
docs/SPEC.md に、4人まで遊べる六角形ボードの資源獲得ゲームの完全なルールと実装方針を書いた。
これを読んだうえで、次の方針で作ってほしい。

- 技術構成：Vite + React + TypeScript。最終的に Vercel にデプロイし、オンライン同期は Supabase を使う。
- 名前・画像：公式の名称・イラスト・ロゴは使わない。盤面やカードはSVGと絵文字でシンプルに自作する。仮タイトルは「開拓ボードゲーム」。
- 設計の最重要ルール：ゲームロジックはUIから完全に切り離した純粋関数にする。
  `applyAction(state, action, playerId) => { state, error }` の形で、
  不正な操作はすべてここで弾く。後でサーバー側でも同じコードを動かすため、
  ブラウザ専用APIや乱数の直接呼び出しをロジック内に書かない（乱数は引数で渡す）。
- ロジックには Vitest でユニットテストを書く。特に「距離ルール」「最長交易路」「7の処理」「資源不足時の配布」は必ずテストする。
- スマホでも遊べるレイアウトにする（盤面はタップ操作前提）。

まずはフェーズ1だけやってほしい：
フェーズ1＝1台の端末で2〜4人が交代で遊べる（ホットシート）ローカル版。SPECのルールをすべて実装する。
作業に入る前に、ファイル構成とデータ構造（座標系・頂点/辺のID設計）を提案して、私の確認を取ってから進めて。
```

フェーズ1が動いたら、次に貼る指示文：

```
フェーズ2として、docs/SPEC.md の「オンライン化の方針」に従って Supabase でオンライン対戦にしてほしい。
部屋を作る→URLを友達に送る→参加→全員そろったらホストが開始、の流れにする。
作業前に、必要なSupabaseの設定手順（私が管理画面でやること）を先に一覧で教えて。
```

## 2. 構成要素（4人用の基本セット）

| 要素 | 数 |
|---|---|
| 地形タイル | 計19枚：森4（木材）、牧草地4（羊毛）、畑4（小麦）、丘陵3（レンガ）、山地3（鉄鉱石）、砂漠1（産出なし） |
| 数字チップ | 計18枚：2と12が各1枚、3・4・5・6・8・9・10・11が各2枚。7は無い。砂漠には置かない |
| 港 | 計9か所：3:1の汎用港×4、2:1の専用港×5（資源ごとに1つ） |
| 資源カード | 5種×19枚＝95枚（銀行） |
| 発展カード | 計25枚：騎士14、街道建設2、収穫（任意の資源2枚）2、独占2、勝利点5 |
| 各プレイヤーの駒 | 開拓地5、都市4、道15（これ以上は建てられない） |
| 特別カード | 最長交易路（2点）、最大騎士力（2点） |
| その他 | サイコロ2個、盗賊1個 |

プレイ人数は3〜4人。

## 3. 盤面の構造（実装上の定義）

- 地形は半径2の六角形グリッド（中心1＋6＋12＝19マス）。アキシャル座標（q, r）推奨。
- 「交差点」＝タイルの角。開拓地・都市はここにだけ置ける。19マスの盤面で54か所。
- 「道の辺」＝タイルの辺。道はここにだけ置ける。1辺に道は1本まで。72か所。
- 外周の辺も道を置ける（海岸沿い）。海岸の交差点は1〜2枚のタイルにしか接しない。
- 港は外周上の9か所に配置し、それぞれ海岸の辺1本（＝交差点2か所）に対応する。港に接する交差点に開拓地/都市があればその港を使える。
- 頂点・辺は、隣接タイル・隣接頂点・隣接辺をすぐ引ける隣接表を事前計算しておく。

### 盤面の作り方
1. **初心者用固定配置**：公式の推奨配置を再現する必要はない（著作権配慮のため）。代わりにバランスの良い固定配置を1つ自作してよい。
2. **ランダム配置（メイン）**：
   - 19枚の地形をシャッフルして配置。
   - 港の種類9つをシャッフルして9か所の港位置に配置。
   - 数字チップ18枚を砂漠以外にランダム配置。ただし**6と8（赤い数字）同士が隣接してはいけない**。隣接したら入れ替える／再抽選する。
   - 盗賊は砂漠に置く。
- 数字チップには出やすさ（点の数）を表示する：2/12=1、3/11=2、4/10=3、5/9=4、6/8=5。

## 4. 初期配置フェーズ（スネーク順）

1. 全員がサイコロを振り、最も大きい人がスタートプレイヤー（オンラインでは乱数で決定してよい）。
2. **1巡目**：スタートプレイヤーから時計回りに、各自「開拓地1つ＋それに隣接する道1本」を置く。
3. **2巡目**：最後の人から逆順（反時計回り）に、各自「2つ目の開拓地＋それに隣接する道1本」を置く。スタートプレイヤーが最後になる。
4. 2つ目の開拓地は1つ目とつながっていなくてよい。道は2つ目の開拓地に接していること。
5. 初期配置でも**距離ルール**（後述）は必ず適用。
6. **2つ目の開拓地に隣接する地形1枚につき1枚ずつ**、その資源を銀行から受け取る（砂漠は無し）。
7. その後、スタートプレイヤーから通常ターンを開始。全員開始時点で2点。

---

## 5. 手番の流れ

公式の「交易/建設フェーズ統合ルール」を採用する（経験者推奨ルール）：

1. **（任意）発展カードを1枚使う** — サイコロの前でも使える（騎士など）。
2. **サイコロを振る（必須）** → 資源産出、または7の処理。
3. **交易と建設を好きな順で何度でも**（交易→建設→交易…可。建てたばかりの開拓地の港もその手番中に使える）。
4. 発展カードの使用は**手番中いつでも1枚まで**（騎士か進歩カード。勝利点カードは別扱い）。
5. 手番終了を宣言 → 左隣（次のプレイヤー）へ。

---

## 6. 資源産出

- 出目と同じ数字チップの地形が産出する（盗賊のいるタイルは産出しない）。
- そのタイルに接する開拓地1つにつき1枚、都市1つにつき2枚。
- 全プレイヤー（手番以外の人も）受け取る。
- **資源不足ルール**：ある資源について、全員の受取合計が銀行の残りより多い場合、その資源は**誰も受け取らない**。
  - 例外：その資源を受け取るのが**1人だけ**なら、銀行に残っている分だけ渡す（残りは消える）。
  - 他の種類の資源の配布には影響しない。

---

## 7. 「7」が出たとき（盗賊）

1. 誰も資源を受け取らない。
2. 資源カードを**8枚以上**持っている全員が、**半分（切り捨て）**を自分で選んで銀行に捨てる（例：9枚→4枚捨てる）。
   - オンラインでは該当者全員が同時に選択し、全員終わるまで次に進まない。
3. サイコロを振った人は盗賊を**今と別の**タイル（砂漠も可）に**必ず**移動する。
4. 移動先タイルに開拓地/都市を持つ**他プレイヤー**から1人選び、その人の資源カードを**ランダムに1枚**奪う。
   - 対象が1人なら自動、複数なら選ぶ。対象がいなければ奪わない。対象の手札が0枚なら何も得られない。
5. その後、交易/建設に進む。

---

## 8. 建設（コストと条件）

| 建設物 | コスト | 条件 |
|---|---|---|
| 道 | レンガ1＋木材1 | 自分の道・開拓地・都市につながる辺。他人の開拓地/都市がある交差点を通り抜けて延ばせない |
| 開拓地 | レンガ1＋木材1＋羊毛1＋小麦1 | 自分の道につながる空き交差点。距離ルールを満たす |
| 都市 | 鉄鉱石3＋小麦2 | 自分の開拓地を置き換える（開拓地の駒は手元に戻り再利用可） |
| 発展カード | 鉄鉱石1＋羊毛1＋小麦1 | 山札が残っていること |

- **距離ルール**：開拓地を置く交差点に隣接する3つの交差点すべてが空いていること（自分の建物も含めて不可）。
- 駒の上限（開拓地5・都市4・道15）を超えて建てられない。開拓地5つ使い切ったら、都市化して開拓地を手元に戻すまで新しい開拓地は建てられない。
- 支払った資源は銀行に戻る。
- 資源と在庫がある限り、1手番に何個でも建てられる。

---

## 9. 交易

### プレイヤー間交易
- **手番プレイヤーとだけ**交易できる。手番でない人同士は交易不可。
- 交渉は自由（手番プレイヤーが提案、他の人も対案を出せる）。
- 禁止：タダであげる、同じ資源同士の交換（例：羊毛2⇔羊毛1）、発展カードの交易。
- 提案→相手が承認で成立。手番プレイヤーが拒否したら不成立。

### 海上交易（銀行）
- 自分の手番中のみ。
- 常に4:1（同じ資源4枚→好きな資源1枚）。
- 3:1港に建物があれば、同じ資源3枚→1枚。
- 2:1専用港に建物があれば、**その資源だけ**2枚→1枚（他の資源には3:1も適用されない。3:1港を別に持っていれば3:1は使える）。
- 複数回まとめて可（例：鉄2:1港で鉄4枚→任意2枚）。

---

## 10. 発展カード

- 購入時は山札の一番上を引き、手札に**非公開**で持つ。山札が尽きたら購入不可。捨て札を再利用しない。
- **購入したその手番には使えない**（勝利点カードで勝利する場合のみ例外）。
- 使えるのは**1手番に1枚まで**（騎士か進歩カード）。サイコロ前でも可。
- 譲渡・交易不可。

| カード | 効果 |
|---|---|
| 騎士（14） | 盗賊を移動し、7のときと同じく1枚奪う（捨て札処理は無し）。使った騎士は表向きで自分の前に残る |
| 街道建設（2） | 通常ルールに従い道を2本無料で置く（在庫が1本なら1本だけ） |
| 収穫（2） | 銀行から好きな資源を2枚（同種でも可）。その手番の建設に使える。銀行に無い資源は取れない |
| 独占（2） | 資源を1種類宣言。他の全員がその資源を全部あなたに渡す |
| 勝利点（5） | 1点。非公開のまま所持し、自分の手番に10点に達したときに公開して勝利。同じ手番に何枚でも公開可、買ったその手番でも可 |

- 進歩カード（街道建設・収穫・独占）は使ったらゲームから除外。

---

## 11. 最長交易路（2点）

- 分岐を含まない**一続きの道の長さ**で判定（分岐がある場合は最長の1経路のみ数える）。同じ辺を2度通らない経路の最大長。
- **5本以上**を最初に作った人が獲得。それより**長い**道を作った人が即座に奪う（同じ長さでは奪えない）。
- **他人の開拓地/都市が経路の途中の交差点にあると、道はそこで分断される**（空き交差点に開拓地を建てて相手の道を切れる）。
- 分断などで長さが変わったときの特例：
  - 保持者の道が短くなっても、まだ単独または同率1位なら保持者が維持。
  - 保持者が1位でなくなり、新しい1位が**同率で複数**いる場合 → カードは誰のものでもなくなる。
  - 5本以上の人が誰もいなくなった場合 → 誰のものでもなくなる。
  - 誰のものでもない状態から、単独1位（5本以上）が現れたらその人が獲得。
- 実装：道の建設時・開拓地の建設時（相手の道を切る可能性）に全員分を再計算する。DFSで各辺から探索。

## 12. 最大騎士力（2点）

- 使用済みの騎士が**3枚以上**になった最初の人が獲得。
- それより**多く**使った人が即座に奪う（同数では奪えない）。

---

## 13. 勝利点と勝利条件

- 開拓地1点、都市2点、最長交易路2点、最大騎士力2点、勝利点カード1枚1点。
- **自分の手番中に10点以上**になった時点で即勝利（建設直後やカード公開時にチェック）。
- 他人の手番中に10点に達しても勝利しない。自分の次の手番まで待つ。
- 他のプレイヤーに見える点数には、非公開の勝利点カードを含めない（本人の画面には含めて表示）。

---

## 14. 公開・非公開情報

- 公開：盤面、各プレイヤーの資源カード**枚数**、発展カードの**枚数**、使用済み騎士、特別カード、銀行の残り資源、発展カード山札の残り枚数。
- 非公開：各プレイヤーの資源カードの**中身**、未使用の発展カードの中身。
- 盗賊で奪われた資源の種類は、奪った人と奪われた人だけが見られる。

---

## 15. オンライン化の方針（フェーズ2）

- Supabase：匿名ログインでプレイヤーを識別。部屋ごとに `games`（公開状態）と、プレイヤーごとの非公開状態（手札・発展カード）を分けて保存し、RLSで本人しか読めないようにする。
- すべての操作は Supabase Edge Function 経由で送り、サーバー側で `applyAction` を実行して検証・保存する（クライアントは状態を直接書き換えない）。乱数（サイコロ・盗み・カードを引く）もサーバー側で生成。
- クライアントは Realtime で状態の変更を購読して画面を更新。
- 再接続：ページを閉じて開き直しても、同じ匿名ユーザーなら席に戻れること。
- 注意：Supabaseの無料プランは、しばらく使わないとプロジェクトが一時停止されることがある（管理画面から再開できる）。遊ぶ前に確認すること。
